## Data Architecture & Governance
- **Raw Data (`data/raw/`):** Stores immutable, date-stamped daily OHLCV historical snapshots fetched via `yfinance` with absolute project-root path resolution.
- **Processed Data (`data/processed/`):** Differs from raw data by isolating the latest raw snapshots, normalizing timestamps to timezone-free dates, and calculating core technical features (`Daily_Return`, `SMA_20`, `SMA_50`, `Volume_SMA_20`).
- **Model-Ready Dataset (`data/ml_ready/`):** Combines point-in-time features with forward target labels ($y_T = \mathbb{1}[\max(P_{T+11},\ldots,P_{T+15}) \ge 1.05P_T]$) across an explicit 4-stock canonical whitelist while enforcing unique key assertions.
- **Leakage Safeguard:** Future-derived audit columns (`Max_Close_T11_T15`, `Max_Return_T11_T15`, and `Target`) are strictly separated and excluded from model feature inputs.
- **Documentation:** Full specifications are maintained under `docs/` (`data_schema.md`, `docs/data_dictionary.md`, and `docs/data_quality_rules.md`).
